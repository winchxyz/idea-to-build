# Examples

Real brainstorm transcripts that show the methodology in action — especially the parts you can't fake: the critic finding a flaw, a hypothesis collapsing under a premortem, a plan with actual gates.

## Why transcripts, not screenshots

This directory holds **markdown transcripts**, not images. Screenshots can't be searched, copied, or diffed, they bloat the repo, and they go stale the moment the UI changes. The product here *is the text* — so we keep it as text.

## Format

Each example is one markdown file: `examples/<short-slug>.md` (e.g. `examples/saas-pricing-pivot.md`).

Two acceptable styles:

1. **Raw transcript** — the cleaned-up conversation, top to bottom. Honest and fast.
2. **Annotated case study** *(preferred)* — the same transcript with short callouts pointing out what the methodology did:
   > 📝 **Note:** here the Critic ran a premortem and surfaced the churn assumption nobody had tested.

Copy [`TEMPLATE.md`](TEMPLATE.md) to start.

## Before you commit a transcript — privacy checklist

- [ ] The idea is **safe to make public** (use a throwaway/illustrative idea, or get sign-off if it's a real project).
- [ ] No names, emails, client data, revenue figures, or credentials you don't want public.
- [ ] Dead-end tangents trimmed so the example stays readable.
- [ ] If the transcript is **illustrative rather than a real session**, say so explicitly at the top. Never present a fabricated transcript as real — factual honesty is the whole point of this project.
